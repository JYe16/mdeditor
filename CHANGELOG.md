# Changelog

## 1.1.0

macOS. The Windows app gets the same changes next (see `windows/HANDOFF-v1.1.md`).

- Double-click a word in the preview to jump to its source in the editor. The matching text is selected and brought on
  screen; the preview does not move. In preview-only view, double-click still just selects the word.
- New app icon: the app's own split layout in one shape, source on the left and rendered result on the right, with one
  "M" across the seam.
- Double-clicking a link in the preview no longer opens it twice.

## 1.0.1

- New app icon, in the same visual style as SysMonitor.

## 1.0.0

- Initial release: split editor / live preview, scroll sync by source line, GitHub-flavored Markdown, code highlighting,
  KaTeX math, list continuation, formatting shortcuts, find & replace, print / PDF export, English + Simplified Chinese UI.
