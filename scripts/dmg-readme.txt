MDEditor — Markdown editor with live preview
============================================

INSTALL
  1. Drag MDEditor into the Applications folder.
  2. Open it from Applications / Launchpad.

FIRST LAUNCH ON ANOTHER MAC
  This app is not notarized by Apple (no paid developer account), so macOS may say
  it "can't be opened" the first time. Pick ONE of these:

  A) Open System Settings > Privacy & Security, scroll down, and click
     "Open Anyway" next to MDEditor. (On older macOS: right-click the app > Open.)

  B) Or run this once in Terminal:
       xattr -dr com.apple.quarantine /Applications/MDEditor.app

  Files copied by USB drive, scp or a network share are usually not blocked at all.

安装
  1. 把 MDEditor 拖进"应用程序"文件夹。
  2. 从"应用程序"或启动台打开。

在其他 Mac 上首次打开
  本应用未经 Apple 公证（没有付费开发者账号），首次打开时系统可能提示"无法打开"。
  任选其一：

  A) 打开 系统设置 > 隐私与安全性，向下滚动，点击 MDEditor 旁边的"仍要打开"。
     （旧版 macOS：右键点击应用 > 打开。）

  B) 或在终端执行一次：
       xattr -dr com.apple.quarantine /Applications/MDEditor.app

  通过 U 盘、scp 或局域网共享拷贝的文件通常完全不会被拦截。
